# 신약 배합 생성기 실행 안내

지원 환경은 Windows 11 x64 비관리자 계정입니다.

1. 받은 ZIP 파일을 원하는 폴더에 모두 풉니다.
2. 인터넷에 연결합니다. 첫 실행에는 Python과 필요한 프로그램을 내려받습니다.
3. `start.bat`을 더블클릭합니다.
4. 첫 화면에서 모델 종류와 모델 전체 이름을 고릅니다.
5. 본인의 API 키를 입력하고 `확인`을 누릅니다.
6. 열린 연구 화면에서 배합 질문을 입력하고 조성표를 생성합니다.
7. 생성된 후보는 각 카드의 `엑셀 저장` 버튼으로 하나씩 저장할 수 있습니다.
8. 결과 아래 `이 결과에 이어서 질문`에 후속 요청을 적습니다. 조성을 바꾸라는 말(예: "총중량 650 mg 으로")은 요청을 고쳐 다시 생성하고, 결과를 묻는 말(예: "왜 이 결합제를 골랐어?")은 현재 표의 근거로 답합니다. 답변 문장마다 근거인지 일반 지식인지 표시됩니다.
9. `이 결과 저장`을 누르면 `%LOCALAPPDATA%\PhramaProto\results\` 아래 폴더에 결과 HTML·엑셀·해설·요청 기록이 저장됩니다. 위쪽 `저장된 작업` 버튼을 누르면 옆에 목록이 열리고, 거기서 열기, 이어서 질문, 삭제를 할 수 있으며 `저장 폴더 열기`로 탐색기에서 바로 볼 수 있습니다. 저장 파일에 API 키는 들어가지 않습니다.
10. 위쪽 `게이트 안내` 버튼은 다섯 게이트의 뜻을 보여 줍니다. 오른쪽 아래 해·달 버튼으로 밝은 화면과 어두운 화면을 바꾸고(기본은 밝은 화면, 선택은 `%LOCALAPPDATA%\PhramaProto\preferences.json`에 기억), `인쇄` 버튼으로 결과와 질의응답만 인쇄합니다.
11. 다 쓰면 `로그아웃 (API 키 삭제)`을 눌러 메모리의 키를 지웁니다.

API 키는 실행 중인 프로그램의 메모리에만 보관되며 프로그램을 끄면 사라집니다. 브라우저를 새로고침해도 키가 남아 있으면 첫 화면에 `저장된 키로 계속` 버튼이 나타나 다시 넣지 않아도 됩니다. SQLite와 로컬 웹 프로그램 자체에는 서버 요금이 없지만, 외부 AI API 호출은 과금 대상입니다.

이 프로그램은 연구 검토용 시제품입니다. 생성된 배합과 근거는 반드시 사람이 검토해야 합니다.

실행이 안 되면 `%LOCALAPPDATA%\PhramaProto\logs\bootstrap.log`의 마지막 오류 코드를 담당자에게 전달하세요. 이전 버전으로 돌아가야 하면 현재 폴더를 수정하지 말고, 이전에 검증된 ZIP을 새 폴더에 다시 풀어 실행하세요.
