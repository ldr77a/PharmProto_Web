API 설정

외부 AI API 호출은 과금 대상입니다.

API 키는 이 프로그램이 켜져 있는 동안 메모리에만 두고 파일에 저장하지 않습니다. 화면의 로그아웃을 누르면 바로 지워집니다.

게이트 판정 안내 열기·닫기
  1. 게이트1 사용량 범위

    각 부형제의 함량이 KG DB 내 실제 배합 데이터의 일반적인 사용범위(p5~p95)에 포함되는지 확인합니다.

  2. 게이트2 제조성 대리지표

    결합제 존재 여부 및 붕해제·활택제 등의 비율을 이용해 제조 가능성을 간접적으로 확인합니다.

  3. 게이트3 총량 제약

    전체 성분의 중량 합이 목표 총중량을 넘지 않는지 검증합니다.

  4. 게이트4 조성 합계

    공정 중 제거되는 성분을 제외한 조성비 합계가 100±0.5%인지 확인합니다.

  5. 게이트5 필수 기능 구성

    제형 제조에 필요한 기능이 모두 포함됐는지 확인합니다.
